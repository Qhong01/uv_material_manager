# UV & Material Manager for Blender

Blender 的专业 UV 与材质管理插件（支持 Blender 4.3+ / 5.2+ LTS）。

## 主要功能特性

### 1. 材质管理 (Material Manager)
- **一键刷新全部材质贴图**：位于材质面板最顶端，一键重新载入所有外部更新的图像贴图并刷新材质球预览（相当于全局一键 Alt+R）。
- **多材质列表与实时缩略图**：自动调度后台材质缩略图生成与实时刷新。
- **4 核心快捷操作栏**：一键赋予材质、Principled BSDF 基础颜色实时拾色器、单材质同步/恢复、删除材质。
- **源材质着色器同步/恢复**：一键全局或单项同步源材质节点树及参数，支持一键无损复原。
- **本地持久化材质模板库**：支持跨工程、跨文件保存材质模板，在插件首选项中支持一键导入与导出 `.blend` 材质库。

### 2. UV 管理 (UV Manager)
- **多 UV 层管理与渲染高亮**：直观管理网格的多 UV 通道，仅高亮当前激活渲染层。
- **选区 UV 复制与粘贴**：支持复制当前选中的 UV 块并粘贴到目标层。
- **UV 编辑器侧边栏快速集成**：在 3D 视图与 UV 编辑器侧边栏无缝调用。
- **UV 棋盘格检查**：内置多种分辨率与色调的 UV 贴图检查工具。

### 3. 修改器管理 (Modifier Manager)
- **修改器列表与紧凑布局**：原生风格修改器管理，支持应用、删除、拖拽排序与联动批量折叠。

## 安装方式
1. 下载 `uv_material_manager.zip`。
2. 打开 Blender，进入 `编辑 (Edit) -> 偏好设置 (Preferences) -> 插件 (Add-ons)`。
3. 点击右上角“安装”选择该 zip 文件并勾选启用即可。
